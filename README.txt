# Ambati Homes — RRR IKON landing page

Replace your existing page with `index.html`.

## Image files expected
Put these in `assets/`:
- rrr-ikon-hero.jpg — main building image
- floor-plan.jpg — floor plan
- gallery-1.jpg through gallery-5.jpg — project/gallery images
- rrr-ikon-brochure.pdf — brochure

## Important
1. Replace `919999999999` in both WhatsApp links with the real WhatsApp number.
2. If your project already has image files, simply rename/change the `src="assets/..."` paths.
3. The layout is responsive for desktop, tablet and mobile.
4. If your existing project is React/Vite/Next.js, the same markup/CSS can be split into components after you confirm the stack.
